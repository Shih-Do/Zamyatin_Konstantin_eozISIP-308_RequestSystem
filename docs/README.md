# RequestSystem
Система учёта заявок для учебного заведения.

## Назначение
Автоматизация обработки обращений, исключение потери информации и контроль сроков выполнения задач.

## Функции
- Регистрация заявок с уникальными номерами
- Ролевая модель доступа (Заявитель, Исполнитель, Оператор, Администратор)
- Контроль статусов и истории изменений

## Стек технологий (планируемый)

- Backend: Django
- Database: PostgreSQL
- Frontend: HTML/CSS/JS
