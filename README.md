# RequestSystem 

Система учёта заявок для учебного заведения. 

## Назначение 
Автоматизация обработки обращений, исключение потери информации и контроль сроков выполнения задач. 

## Функции 
- Регистрация заявок с уникальными номерами (формат `#YYYY-NNNN`).
- Ролевая модель доступа (Заявитель, Исполнитель, Оператор, Администратор). 
- Контроль статусов и истории изменений (Audit Log).
- REST API для взаимодействия с внешними клиентами.

## Стек технологий
- **Backend:** Python 3.12, FastAPI.
- **Database:** SQLite (с возможностью миграции на PostgreSQL).
- **ORM:** SQLAlchemy.
- **Frontend:** HTML/CSS/JS (в разработке).

## 🚀 Запуск проекта локально

Для запуска проекта необходимо иметь установленный Python (версия 3.10 или выше).

### 1. Клонирование репозитория
```bash
git clone https://github.com/Shih-Do/Zamyatin_Konstantin_eozISIP-308_RequestSystem.git
cd Zamyatin_Konstantin_eozISIP-308_RequestSystem
```

### 2. Настройка виртуального окружения
Создайте и активируйте виртуальное окружение:
```bash
# Создание окружения
python -m venv venv

# Активация (для Windows / Git Bash):
source venv/Scripts/activate
	
# Для Linux/Mac: 
source venv/bin/activate
```

### 3. Установка зависимостей
Установите все необходимые библиотеки:
```bash
pip install -r requirements.txt
```

### 4. Инициализация базы данных
Убедитесь, что в папке docs/sql/ находится файл базы данных request.db. 
Если его нет, создайте его, выполнив скрипты schema.sql и seed.sql через DB Browser for SQLite.

### 5. Запуск сервера
Запустите локальный сервер разработки:
```bash
uvicorn src.main:app --reload
```
Приложение будет доступно по адресу: http://127.0.0.1:8000

## Документация API
После запуска сервера интерактивная документация (Swagger UI) доступна по адресу:
http://127.0.0.1:8000/docs

Основные эндпоинты:
| Метод	| Путь |	Назначение |	Ожидаемый результат |
| --- | --- | --- | --- |
| GET	| /api/v1/requests/	| Список заявок с поиском и фильтрацией |	HTTP 200 + JSON-массив |
| GET	| /api/v1/requests/{id}	| Получение заявки по ID	| HTTP 200 или 404 |
| POST	| /api/v1/requests/	| Создание новой заявки |	HTTP 201 + созданный объект |
| PATCH	| /api/v1/requests/{id} |	Изменение заявки (статус, исполнитель) |	HTTP 200 или 404 |
| DELETE	| /api/v1/requests/{id} |	Архивация заявки (смена статуса) |	HTTP 204 или 404 |
| `GET` | `/api/v1/users` | Справочник пользователей | HTTP 200 + JSON-массив |
| `GET` | `/api/v1/statuses` | Справочник статусов | HTTP 200 + JSON-массив |
| `GET` | `/api/v1/categories` | Справочник категорий | HTTP 200 + JSON-массив |

Пример запроса на создание заявки (POST):
```json
{
  "title": "Не работает Wi-Fi",
  "description": "Нет подключения в аудитории 305",
  "priority": "Высокий",
  "category_id": 1,
  "author_id": 4
}
```
