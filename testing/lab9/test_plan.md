# План тестирования RequestSystem (ЛР №9)

## 1. Объект тестирования
REST API системы учёта заявок (RequestSystem). Версия 1.0.0.

## 2. Тестовая среда
*   **ОС:** Облачная среда GitHub Codespaces (Ubuntu Linux).
*   **Среда выполнения:** Docker-контейнер (Python 3.12, FastAPI).
*   **База данных:** SQLite (`docs/sql/request.db`).
*   **Инструмент тестирования:** Swagger UI (встроенная документация FastAPI).

## 3. Что проверяется
*   Создание, чтение, редактирование и архивация заявок (CRUD).
*   Работа поиска и фильтрации.
*   Валидация входных данных (Pydantic).
*   Обработка ошибок (HTTP-коды 404, 422).
*   Работа справочников (пользователи, статусы, категории).
*   Проверка Health-check (`/health`).

## 4. Что НЕ входит в проверку
*   Нагрузочное тестирование (проверка под высокими нагрузками).
*   Тестирование пользовательского интерфейса (UI), так как фронтенд находится в разработке (используется Swagger).
*   Проверка безопасности (авторизация, роли), так как в текущей версии API она не реализована.

## 5. Критерии начала и завершения
*   **Начало:** Приложение успешно развернуто в Codespaces, база данных инициализирована.
*   **Завершение:** Выполнены все 20+ тест-кейсов, результаты зафиксированы, найденные дефекты описаны в баг-репортах.
